# Aionik brand assets

Navy palette, generated 1 Sep 2026 to match the site restyle.
Mark and wordmark are deliberately separate files. Do not bake them
into one image; the lockup is assembled in layout, not in the asset.

## Logo (the AK monogram only, no wordmark)
1000 x 1000, matching the previous monogram files, and the size to use
for a LinkedIn company profile picture. The mark fills 60% of the canvas
width, the same proportion as the earlier version, so it survives
LinkedIn's circular crop.

- aionik-logo-navy-on-white-1000.png    light backgrounds
- aionik-logo-white-on-navy-1000.png    dark backgrounds
- aionik-logo-navy-transparent-1000.png overlay on light artwork
- aionik-logo-white-transparent-1000.png overlay on dark artwork

## Wordmark (the word AIONIK only, no mark)
1800 x 420, IBM Plex Sans 600, letterspaced to match the site nav.

- aionik-wordmark-navy-on-white.png
- aionik-wordmark-white-on-navy.png
- aionik-wordmark-navy-transparent.png
- aionik-wordmark-white-transparent.png

## Vector source
mark-*.svg are the monogram as vector, for any size. The site itself
uses assets/aionik-mark.svg, which inherits currentColor.
